# Viraj Gandhi — 2026 Blue Portfolio

This version is a single modern portfolio website. There is **no retro / Back to '96 mode**.

## Included
- Modern blue 2026 visual system
- Animated dot-matrix VIRAJ GANDHI hero
- Scroll reveal and hover animations
- Real project sections based on your WAID, Netflix analysis, SQL/database, R/DATA202 and systems work
- GitHub links using: https://github.com/VTXZenyx
- Contact email: gandhiviraj2006@gmail.com
- Embedded `resume.pdf` section with Open + Download buttons
- Reaction Game
- Snake
- SQL Quiz
- Local best-score saving in the browser
- Responsive mobile layout

## Files
- `index.html` — page structure/content
- `style.css` — all styling + animations
- `script.js` — hero animation, modals and games
- `resume.pdf` — placeholder resume PDF
- `assets/` — styled project-preview SVGs

## Replace the resume
When your real CV is ready, name it exactly:

`resume.pdf`

Then replace the placeholder file in this folder. You do not need to edit the HTML because every Resume button already links to `resume.pdf`.

## Replace project preview graphics
The current SVGs are styled project previews, not claimed screenshots. When you have real screenshots, either:
1. replace each SVG file with your own image and update the file extension in `index.html`, or
2. keep the SVG previews and add screenshots inside the project cards/modals.

## Project GitHub links
Right now project buttons point to your GitHub repository list because exact repository URLs were not supplied. Once each project has its own repo, replace:

`https://github.com/VTXZenyx?tab=repositories`

with that project's exact URL.

## Run locally
Double-click `index.html`, or open the folder with VS Code and use Live Server.

## Publish
This is a static site, so it can be hosted on GitHub Pages, Netlify, Vercel or similar static hosting.
